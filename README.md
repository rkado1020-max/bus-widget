# 버스 위젯

내 위치에서 가장 가까운 정류장을 찾아, 도착지까지 가장 빨리 가는 버스 노선을 실시간으로 보여주는 위젯이에요. (경기도 버스 기준)

## 준비
1. [공공데이터포털](https://www.data.go.kr)에서 아래 세 가지를 활용신청하고 일반 인증키를 받아요.
   - 경기도_정류소 조회
   - 경기도_버스노선 조회
   - 경기도_버스도착정보 조회 (버스위치정보 조회 포함)
2. `config.example.json`을 `config.json`으로 복사하고 인증키를 넣어요. (이 파일은 git에 올라가지 않아요)

## 실행
```
node server.js
```
브라우저에서 http://localhost:3939 를 열어요. Windows는 `버스위젯_실행.bat`으로 작은 창에 띄울 수 있어요.

## 참고
- 위치 정보는 `localhost` 또는 https 주소에서만 받을 수 있어요.
- 소요시간은 도착지 정류장의 도착예정으로 역산한 값이에요. 버스가 없으면 정거장당 2분으로 어림잡아요.

## 링크로 배포하기 (Vercel)
1. 이 저장소를 Vercel에서 Import해요. (서울 리전 `icn1`로 설정돼 있어요)
2. Settings → Environment Variables에 `BUS_API_KEY`로 인증키를 넣고 Deploy해요.
3. 나온 https 주소를 공유하면 돼요. 위치 정보도 https라서 휴대폰에서 바로 쓸 수 있어요.
- 인증키는 서버에만 있고 화면 코드에는 들어가지 않아요. 다만 모든 사용자의 호출이 한 키로 잡혀요.
